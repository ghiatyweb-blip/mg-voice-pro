MG Voice Pro
============

هذه نسخة ويب حقيقية بواجهة Chrome + خادم Node.js يستخدم @travisvn/edge-tts لتوليد MP3 من أصوات Microsoft Edge TTS Neural.

تشغيل على الكمبيوتر:
1) ثبّت Node.js 20 أو أحدث.
2) افتح Terminal داخل المجلد.
3) نفّذ: npm install
4) ثم: npm start
5) افتح: http://localhost:3000

للاستضافة:
- ارفع المجلد إلى خدمة استضافة Node.js تدعم npm install وnpm start.
- لا تضع مفاتيح API؛ هذه النسخة لا تحتاج مفتاح API.
- بعد النشر افتح رابط الموقع من Chrome على الهاتف.

الأصوات المصرية: ar-EG-ShakirNeural و ar-EG-SalmaNeural.
